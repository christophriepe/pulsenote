# packages/fhir-mapping

Extraction: turns a case's `QuestionnaireResponse` into IPS-aligned FHIR R4 resources (`Encounter`, `Observation`, `Condition`, …) and, on request, an IPS document bundle. See "FHIR data model" in the root README and the data flow in `packages/form-definitions`.

**Owner:** Area 2 (Backend & FHIR / IPS modelling)
