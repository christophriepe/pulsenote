# apps/web

The PulseNote web app (React): one app with one login and two views.

- `src/features/case-form/`: case form. Three-step wizard on phones, single page on the PC.
- `src/features/dashboard/`: case list, editing, free-text and IPS export, analytics (planned).
- `src/auth/`: shared login.
- `src/components/`: shared UI building blocks.

**Owner:** Area 4 (Frontend & prototype)
